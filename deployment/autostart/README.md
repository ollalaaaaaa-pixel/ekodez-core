# Wrapper: готовность к следующему деплою

После команды владельца «применяй» сохранить прежний wrapper в backups и
разместить `reboot-context.ps1` и `run-autostart-hidden.ps1` вместе в
`C:\D\Экодез\scripts\`. Текущие файлы задач и работающие процессы этим коммитом
не изменяются. Новая запись WRAPPER START появится при следующем согласованном
запуске задачи; проверка боевого лога относится к этапу деплоя.

Пишутся события System 1074/6005/6006/41 младше десяти минут: время, ID,
безопасная классификация и код причины 1074, если доступен. Полный текст
события, пользователь и командная строка не записываются. При отсутствии
событий или доступа — явный маркер, запуск сервиса продолжается.

Проверка без запуска сервисов: `powershell -NoProfile -ExecutionPolicy Bypass -File deployment/autostart/test-reboot-context.ps1` (политика меняется только для этого процесса).
