# Маркетинговый сайт ЭКОДЕЗ — локальный прототип

Отдельное приложение React 18 / TypeScript / Tailwind / Framer Motion. Не заменяет внутренний frontend Core и не открывает его API. Исходные чаты, PII и секреты не включены.

```powershell
pnpm install --frozen-lockfile --ignore-scripts
pnpm test
pnpm build
pnpm preview
```

Предпросмотр: http://127.0.0.1:5180. Сборка создаёт 28 статических страниц плюс страницу 404. Встроенный preview нормализует маршруты; будущий хостинг должен отдавать route/index.html, а неизвестные пути — HTTP 404, не главную. robots.txt, meta robots и заголовок локального сервера запрещают индексацию. Это не авторизация: наружу этот preview не открывать.

До релиза нужны утверждённые реквизиты оператора/правовые тексты, проверка лицензии, условия гарантии, домен, реальные материалы бренда, SEO canonical/sitemap под выбранный домен, публичный клиентский сценарий бота и B6. Счётчики и пиксели не установлены. lead_submit не отправляется.

Квиз пока только готовит текст: не собирает имя/телефон и ничего не отправляет в Core. Ссылка в Telegram содержит только код разрешённого источника. Ответы исчезают при перезагрузке. UTM source переносится между страницами; остальные произвольные параметры не переносятся.

Снимки desktop.png, mobile.png, quiz-mobile.png — свидетельства локальной проверки, не утверждённый фирменный дизайн. Проверка браузером: файл tests/browser-check.js для playwright-cli run-code; тест не переходит по внешним ссылкам и не отправляет сообщение.
