# Экодез Core

## Разработка

На Windows, если путь к виртуальному окружению содержит кириллицу, mypy 1.18.2
нужно устанавливать в pure-Python варианте:

```powershell
pip install --no-binary mypy mypy==1.18.2
```

Скомпилированный wheel в таком пути может завершаться с `DLL ImportError`.

## Вход через Telegram Mini App

Backend проверяет подпись Telegram `initData`, сопоставляет числовой Telegram ID
с `OWNER_TG_ID` (роль `owner`) или `ALEXEY_TG_ID` (роль `master`) и выдаёт
подписанную HttpOnly-сессию на 12 часов. Неизвестному ID возвращается общая
подсказка настроить роль в конфиге без раскрытия состава allowlist.

При работе CRM по HTTPS установите `HTTPS_ENABLED=1`: тогда cookie challenge и
сессии получают флаг `Secure`. Раскрытие PII с другого устройства без HTTPS
отклоняется с HTTP 426. Банковские и регистрационные реквизиты плательщика, а
также изменение цен договора доступны только роли `owner`; роль `master` видит
маскированные реквизиты.

Защита challenge от повтора требует миграцию `f1b5d8c0e236`. Таблица
`consumed_challenges` хранит только SHA-256 и время использования UTC.
Уникальный ключ атомарно отклоняет повтор до выдачи сессии, в том числе
при восстановлении исходного cookie. Применять миграцию рабочей БД только
после команды владельца и резервного копирования.
