# AGENTS.md — инструкции для Codex по проекту «Экодез Core»

## 1. Проект и запуск

«Экодез Core» — внутренний пульт управления бизнесом дезинфекции и
дезинсекции. Backend: FastAPI, SQLAlchemy, Alembic и Python 3.12. Frontend:
React, Vite и Ant Design; зависимости устанавливаются через `pnpm`.
Backend запускать из каталога `backend` командой
`.venv\\Scripts\\python.exe -m scripts.run_backend`: конфигурация привязана к
`127.0.0.1` и отключает обработку proxy headers.

## 2. Переменные окружения

Приложение читает документированный список переменных:

- `DATABASE_URL`;
- `TELEGRAM_BOT_TOKEN` (пусто → poller отключён);
- `OWNER_TG_ID` (необязательная);
- `ALEXEY_TG_ID` (необязательная);
- `PII_FERNET_KEY` (шифрование PII в БД).

Добавление переменной разрешается только с явного разрешения Qwen и с
обязательным обновлением этой секции. `SECRET_KEY`, Pydantic Settings и
`VITE_*` не добавлять.

## 3. Безопасность данных

- Деньги хранить и считать только через `Decimal`; в API и UI передавать
  строкой с двумя знаками после запятой.
- Телефон, адрес и имя клиента маскировать в БД, логах и UI. Полные данные
  хранить только в `encrypted_pii` и раскрывать по утверждённому защищённому
  сценарию.
- Не коммитить и не выводить в отчёты `.env`, токены, ключи, `*.db`, XLSX и
  вложения.
- Сервер самостоятельно пересчитывает хеши, классификации и отсечения.

## 4. Этапы и проверки

Этапы мастер-плана выполнять строго по порядку и не переходить к следующему
без команды владельца «далее». Перед коммитом обязательны backend `unittest`,
`ruff`, `black`, `mypy`, frontend `lint` и `build`, а также проверки здоровья.
