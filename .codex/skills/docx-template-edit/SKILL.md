# Безопасное редактирование DOCX-шаблонов

## Назначение

Шаблон редактируется так, чтобы предыдущая версия и сгенерированные документы оставались восстановимыми.

## Ранбук

1. Сохрани исходный шаблон и зафиксируй его SHA-256. Изменения делай в новой версии/копии вне рабочей БД.
2. Проверь список плейсхолдеров и типы таблиц до правки. Не меняй имена полей без проверки всех вызывающих мест.
3. Сгенерируй новый DOCX через текущий docxtpl-процесс, создав версию `vN`. Старые версии не удаляй и не перезаписывай молча.
4. Распакуй результат для проверки текста, плейсхолдеров и структуры таблиц. Проверь, что `{{...}}` не осталось.
5. Проверь обязательные строки, суммы, номера и даты. Затем визуально открой документ и проверь переносы, подписи и колонтитулы.
6. В отчёте укажи исходный SHA, новую версию и результаты машинной/визуальной проверки.

## Чек-лист

- исходный шаблон сохранён;
- версия и SHA зафиксированы;
- плейсхолдеры обработаны;
- таблицы и строка «Итого» корректны;
- старая версия доступна;
- визуальная проверка выполнена.

## Типичные ошибки проекта

- править единственный шаблон на месте;
- удалить v1 после генерации v2;
- проверить только расширение файла;
- забыть таблицу при рендере повторного акта;
- принять документ с незаполненным плейсхолдером.
