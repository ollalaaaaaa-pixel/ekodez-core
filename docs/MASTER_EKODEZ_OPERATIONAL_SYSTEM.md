# MASTER-EKODEZ-OPERATIONAL-SYSTEM

Этапы выполняются строго последовательно. После каждого этапа — полный gate,
коммит, push, отчёт и пауза до команды владельца «далее».

1. PII-маскирование заявок и локальное контролируемое раскрытие.
2. Авторизация владельца: вход по одноразовому коду через Telegram на
   `OWNER_TG_ID`; использовать существующие переменные без новых секретов.
3. Центральная модель объекта и история обработок.
4. Складской учёт препаратов и транзакционное списание.
5. Дашборд KPI.
6. Ежедневная управленческая сводка в Telegram.
7. Журнал пакетов банковского импорта.
8. Мобильный PWA-интерфейс мастеров.
9. Автоматические напоминания.
10. Карта объектов.

Этап авторизации вынесен отдельно и не входит в этап 1. До его реализации
раскрытие PII разрешается только для запросов, у которых
`request.client.host` равен `127.0.0.1` или `::1`; прокси-заголовки не
учитываются.
