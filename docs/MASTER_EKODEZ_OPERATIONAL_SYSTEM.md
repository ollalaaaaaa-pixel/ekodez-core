# MASTER-EKODEZ-OPERATIONAL-SYSTEM

Этапы выполняются строго последовательно. После каждого этапа — полный gate,
коммит, push, отчёт и пауза до команды владельца «далее».

1. PII-маскирование заявок и локальное контролируемое раскрытие.
2. Центральная модель объекта и история обработок.
3. Складской учёт препаратов и транзакционное списание.
4. Дашборд KPI.
5. Ежедневная управленческая сводка в Telegram.
6. Журнал пакетов банковского импорта.
7. Мобильный PWA-интерфейс мастеров.
8. Автоматические напоминания.
9. Карта объектов.

Отдельный security-этап авторизации владельца: вход по одноразовому коду через
Telegram на `OWNER_TG_ID`, с использованием существующих переменных без новых
секретов. Он не входит в этапы 1–9 и выполняется только по отдельной команде.
До его реализации
раскрытие PII разрешается только для запросов, у которых
`request.client.host` равен `127.0.0.1` или `::1`; прокси-заголовки не
учитываются.
