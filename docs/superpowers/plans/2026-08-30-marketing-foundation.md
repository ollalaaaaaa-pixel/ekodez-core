# Marketing Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создать безопасные шаблоны договорных документов и полный пакет стратегической аналитики части A для ЭКОДЕЗ.

**Architecture:** DOCX-шаблоны отделены от клиентских оригиналов и содержат только редактируемые поля; маркетинговые документы используют общий словарь фактов и маркировку `[Ф]/[О]/[Г]`. Внешние площадки остаются неизменными, а переход к исполнению блокируется владельцем.

**Tech Stack:** Markdown, DOCX/OOXML через `python-docx`, визуальная проверка LibreOffice/Poppler, Git `main`.

**Spec:** `docs/superpowers/specs/2026-08-30-marketing-foundation-design.md`

## Global Constraints

- Язык артефактов — русский.
- Полные ИНН, банковские реквизиты, телефоны клиентов, `.env`, базы и вложения не коммитить.
- Подписанные оригиналы договоров не изменять.
- Не выдумывать статистику, частотность, отзывы, цены и гарантии.
- Внешние действия, реклама и публикации не выполнять.
- Часть B начинается только после «стратегия утверждена»; часть C — после следующей команды «далее».
