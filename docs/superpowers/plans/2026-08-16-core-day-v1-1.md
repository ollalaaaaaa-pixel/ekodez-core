# CORE-DAY-V1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить девять фиксированных категорий доходов и постоянный справочник произвольных расходных категорий, управляемый с экрана «День».

**Architecture:** Доходные категории остаются типизированной конфигурацией Python. Расходные категории переносятся в PostgreSQL-модель `ExpenseCategory`; API выдаёт и создаёт записи справочника, а дневной API использует его для проверки и агрегации. Frontend загружает справочник, использует строгие Select и переиспользует одно модальное окно создания категории на desktop и mobile.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2, Alembic, PostgreSQL, unittest, React 19, TypeScript 6, Ant Design 6, Vite 8.

## Global Constraints

- Доходы: ровно 9 утверждённых категорий из CORE-DAY-V1.1.
- Расходы: динамический справочник в PostgreSQL, начальные 7 категорий.
- Денежные значения backend: только `Decimal` / `Numeric(14, 2)`.
- Новые категории создаются без учёта регистра дубликатов и сохраняются постоянно.
- Тач-таргеты мобильного интерфейса: не меньше 44 px.
- Существующие финансовые операции не переписывать.
- `.env`, `tg_offset.json`, вложения, секреты и `backend/sample_order.txt` не коммитить.
- `git add .` запрещён; финальный коммит: `Core: dynamic expense categories and fixed income list v1.1`.

```python
@app.get("/api/expense-categories", response_model=list[ExpenseCategoryOut])
def list_expense_categories():
    with Session(engine) as session:
        return session.scalars(
            select(ExpenseCategory)
            .where(ExpenseCategory.is_active == True)
            .order_by(ExpenseCategory.id)
        ).all()

@app.post("/api/expense-categories", response_model=ExpenseCategoryOut)
def create_expense_category(payload: ExpenseCategoryIn):
    name = payload.name.strip()
    if not name or len(name) > 100:
        raise HTTPException(status_code=422, detail="bad category name")
    with Session(engine) as session:
        existing = session.scalar(
            select(ExpenseCategory).where(
                func.lower(ExpenseCategory.name) == name.lower()
            )
        )
        if existing is not None:
            raise HTTPException(status_code=400, detail="category already exists")
        row = ExpenseCategory(name=name)
        session.add(row)
        try:
            session.commit()
        except IntegrityError as error:
            session.rollback()
            raise HTTPException(
                status_code=400, detail="category already exists"
            ) from error
        session.refresh(row)
        return row
```
