## Семантика — гипотезы, не данные Wordstat

- Тараканы: обработка от тараканов Архангельск; дезинсекция квартиры; тараканы после обработки; повторная обработка от тараканов.
- Клопы: обработка от клопов Архангельск; клопы после обработки; подготовка квартиры к обработке от клопов (отдельная информационная группа, не смешивать с горячими).
- B2B: договор дезинсекции для организации; контроль вредителей объект; обследование с актом; дератизация для бизнеса.
- Плесень: обработка плесени Архангельск; плесень снова на стене; убрать плесень в помещении.
- Клещи: обработка участка от клещей Архангельск; обработка дачного участка.

Минус-фразы для проверки: вакансии, работа дезинфектором, обучение, курсы, видео, бесплатно, своими руками, купить препарат, купить химию, оптом, инструкция препарата, скачать. Не исключать целиком слово «работа»: оно встречается в целевых запросах. Пересечения групп и фактические запросы проверяются после сбора статистики.

## Метрика и UTM

Официальные документы, проверены 08.09.2026: [параметры URL Директа](https://yandex.ru/support/direct/ru/statistics/url-tags), [reachGoal](https://yandex.ru/support/metrica/ru/objects/reachgoal).
Динамические параметры подставляются Директом; локальный макет не имеет реальных campaign_id/ad_id.

Шаблон после выбора домена:
`/quiz?utm_source=yandex_direct&utm_medium=cpc&utm_campaign={campaign_id}&utm_content={ad_id}&utm_term={keyword}`.
Не добавлять телефоны, имена, адреса, текст заявки. В Telegram переносится только разрешённый код источника, не keyword и не PII.

| Цель | Когда считать | Статус |
|---|---|---|
| view_service | блок услуги виден минимум на 50%, один раз за просмотр | Спецификация, не подключена |
| price_start | первый содержательный ответ в квизе | Спецификация, не подключена |
| phone_click | нажатие tel:, не состоявшийся звонок | Спецификация, не подключена |
| telegram_click | переход в бот, не заявка | Спецификация, не подключена |
| lead_submit | только подтверждённое создание заявки сервером | Заблокировано до интеграции B6 |
| b2b_pack_request | подтверждённый сервером запрос обслуживания | Заблокировано до интеграции B6 |
| form_error | код ошибки валидации, без текста полей | Спецификация, не подключена |

CPL = расходы / уникальные подтверждённые заявки. Не считать клики по телефону и боту заявками.
Потолок CPC: НЕ ЗАДАН; дневной бюджет: НЕ ЗАДАН. Не выводить их из неподтверждённой рыночной цены или желаемой конверсии.

## Перед внешним действием

Владелец выбирает домен, даёт авторизованную сессию кабинета, утверждает лимиты и юридические тексты. Сначала создать черновики без запуска, проверить все ссылки и цели на синтетическом контакте. Запуск — только «запускай» и дневной лимит. Ретаргетинг не считать настроенным без реально созданной аудитории.
